### Как я работаю
 
Архитектуру, контракты между модулями и границы ответственности проектирую сам, до первой строчки кода: что на входе и выходе, какие крайние случаи, что считается готовым. Это подход Spec-Driven Development - он даёт воспроизводимый результат вместо угадывания по промпту.
 
AI использую как ускоритель на этапе реализации: Claude Code в терминале, кастомные Agent Skills в формате SKILL.md, sub-agents под изолированные подзадачи, несколько параллельных сессий. За код в репозитории при этом отвечаю я: разбираю логику, покрываю тестами, проверяю поведение на некорректных данных и граничных значениях. Если я не могу объяснить, почему строчка написана именно так, она в проект не попадает.
